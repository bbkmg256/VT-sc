
Vomiting Things será un foro anónimo al estilo 4chan, cualquiera podrá postear (por el momento solo texto) y comentar sobre el post de otra persona.

Las tecnologías a implementar serán django para la creacion del portal web, postgreSQL como motor de base de datos para alojas y almacenar los post, y para la parte visual estará por verse momentaneamente (la idea es que se vea algo retro)...
